## mytcgb - INFORMACIÓN IMPORTANTE / IMPORTANT INFO:

_mytcgb_ es una plataforma web para gestionar y compartir álbumes de juegos de cartas coleccionables (TCG) de forma pública e interactiva, la cual incluye enlaces directos a [Cardmarket](https://cardmarket.com/), como método interactivo para consultar precios de mercado en tiempo real.
